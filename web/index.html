The same Qloo flow is an MCP tool named find_common_ground. Add it to Claude Code with one command.

claude mcp add --transport http common-ground https://common-ground.lipmichal.workers.dev/mcp

Then ask your agent. "Ana loves Radiohead and Bjork, Tom loves Kendrick Lamar and Taylor Swift. Find us a restaurant in Lisbon."
